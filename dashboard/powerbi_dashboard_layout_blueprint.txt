============================================================
DASHBOARD STORYTELLING GOAL
============================================================

The dashboard should simulate:
- AI-assisted industrial monitoring system
- Predictive maintenance control room
- Operational risk management console

The focus should remain on:
- maintenance decisions
- machine health
- operational reliability
- failure prevention

NOT on:
- ML model internals
- technical sklearn details
- excessive experimentation visuals

============================================================
DESIGN PRINCIPLES
============================================================

DO:
- Keep visuals clean
- Maintain industrial feel
- Use operational terminology
- Highlight actionable insights
- Use consistent color coding

DO NOT:
- Overcrowd dashboard
- Add unnecessary charts
- Focus heavily on ML jargon
- Use bright random colors

============================================================
FINAL OBJECTIVE
============================================================

A stakeholder viewing the dashboard should immediately feel:

"This system can help monitor machine health and reduce
unexpected industrial equipment failures."
